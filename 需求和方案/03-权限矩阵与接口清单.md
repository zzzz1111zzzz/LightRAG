## 1. 权限命名约定

```text

workspace:delete
member:read

role:read
role:write
document:read
document:insert
document:delete
document:reprocess
query:read
graph:read
graph:write
pipeline:read
pipeline:run
credential:read
credential:write
credential:revoke
audit:read
```

## 3. 认证与错误语义

| 场景 | 响应 |
|---|---|
| 无 token/API credential | 401 |
| token 无效或已过期 | 401 |
| 用户已认证但不属于目标 workspace | 403，或按资源存在性策略返回统一 404 |
| 用户属于 workspace 但缺少操作权限 | 403 |
| 资源属于当前 workspace 但不存在 | 404 |
| 操作与当前 pipeline 状态冲突 | 409 |
| 请求参数或文件不合法 | 400/422 |

不得通过错误消息泄露其他租户资源是否存在。

## 8. 路由开发检查表

新增或修改任何业务路由时必须确认：

- [ ] 是否明确认证要求。
- [ ] 是否明确所需 permission。
- [ ] workspace 是否从服务端 context 得到。
- [ ] 是否拒绝 body/query/header 对 context 的覆盖。
- [ ] 是否使用正确 workspace runtime。
- [ ] 是否验证资源归属。
- [ ] 是否有审计要求。
- [ ] 是否正确区分 401、403、404、409。
- [ ] 是否有跨 workspace 测试。
- [ ] 是否复核 lock、pipeline、cache 和日志的 workspace 作用域。
